# Правила проекта

- Сохраняйте существующие Rust RPC-клиенты и Cargo workspace. Версии и команды берите из manifests и README.
- Нумерация заданий продолжается в ветках `task/<номер>-<название>`. Работайте в основном репозитории; новые worktree не нужны.
- Имя, символ и описание токена берите из [metadata.json](../../clients/token-client/metadata.json). Обновляйте существующий mint; не создавайте замену для исправления metadata.
- В продуктовых описаниях, metadata и отчётах не добавляйте слова «учебный», «временный», сроки или даты. Сеть и фактические ограничения указывайте точно.
- Word-отчёты оформляйте по существующему образцу, с реальными скриншотами кода и выполненных операций. Документы остаются локально и не входят в Git.
- Не публикуйте keypair, seed phrase и приватные ключи. Используйте существующие игнорируемые каталоги ключей.
- DeFi-клиент должен проверять devnet до отправки транзакций, выполнять simulation и читать итоговые состояния через RPC.
- Сохраняйте посторонние изменения. Перед commit проверяйте полный diff и точные пути; перед push выполняйте fetch и rebase.
