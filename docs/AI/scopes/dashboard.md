# Dashboard

- Источник реализации: `clients/dashboard-client/src/main.rs`; интерфейс — `clients/dashboard-client/web/`. Сохраняйте простой Rust сервер и HTML/CSS/JavaScript без отдельного frontend build.
- HTTP API только читает публичные данные. Для просмотра не нужны private key, подключение кошелька или подпись. Сервер слушает loopback и проверяет devnet перед запуском.
- `/api/config` задаёт начальный кошелёк и сведения о SNTOK из существующего metadata.json. `/api/dashboard?wallet=<PUBKEY>` возвращает баланс, токен-счета, транзакции кошелька и программы.
- `balance.lamports` и `tokens[].amount` — строки целых минимальных единиц. `tokens[].decimals` определяет форматирование в интерфейсе; не переводите суммы в float или JavaScript Number.
- Недоступный раздел возвращается как null с ошибкой, а пустой успешный результат — как пустой массив. В интерфейсе нельзя подменять ошибку RPC нулевым балансом или отсутствием транзакций.
- Ленты показывают ограниченное число последних записей, а не суммарную активность за период. Активность программ относится ко всей сети; транзакции кошелька — к выбранному адресу.
- Источник оформления — styles.css; сохраняйте его цвета, типографику, состояния и адаптивные таблицы. При проверках нужны desktop/mobile, новый адрес, неверный адрес, пустые данные и ошибка RPC.
- Web-файлы встроены через include_str: после их изменения пересоберите dashboard-client. Сборку и тесты запускайте по README и Cargo manifests.
